# GreenQuiz – Sustainability Awareness Quiz

GreenQuiz is a responsive, frontend-only educational website designed to improve students' awareness of environmental issues and sustainable practices through interactive quizzes.

## Features
- Interactive multiple-choice sustainability quiz.
- Questions covering climate change, recycling, energy, water conservation, and biodiversity.
- Instant feedback on answers.
- Score and quiz progress tracking.
- Option to restart the quiz.
- Save the best score automatically using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `greenquiz` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
GreenQuiz can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. The best quiz score is stored locally in the user's browser.
